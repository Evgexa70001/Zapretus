# Zapretus

> Архив технического описания до замены LAB от 18.11.2026. Сведения о старых сборках и восьми LAB ниже сохранены для истории; текущую инструкцию смотрите в `README.md` в корне проекта.

Настольное приложение для Windows x64 с интерфейсом на русском языке.
Движок — winws / WinDivert из Flowseal/zapret-discord-youtube 1.10.4.
22 исходных профиля дополнены 8 экспериментальными профилями LAB, собранными в Zapretus.

## Запуск

Обновлённый интерфейс: `Zapretus-ui.exe`. Круглая иконка питания слева включает/выключает движок (также доступна с клавиатуры). Ссылка медиатеста перенесена под диагностику в карточку стратегии. Game Filter отображается переключателем с ползунком.

В `Zapretus-dark.exe` убрана нижняя подпись, её место отдано журналу. Системный заголовок оформлен в тёмных цветах через DWM Windows 11; стандартные кнопки управления окном сохранены.

### Автозапуск

Сборка `Zapretus-autostart.exe` добавляет переключатель «Автозапуск». Запустите эту версию вручную и включите переключатель. При следующем входе в вашу учётную запись Windows (через 10 секунд) приложение запустится в трее и автоматически включит сохранённую стратегию с сохранёнными настройками Game Filter. До входа пользователя запуск не выполняется. Обычный ручной запуск оставляет движок выключенным.

Используется задача Планировщика Windows `Zapretus.Autostart.<SID пользователя>`, интерактивный токен пользователя и максимальные доступные права. Пароль не сохраняется. Реализация основана на [LogonTrigger](https://learn.microsoft.com/en-us/windows/win32/taskschd/logon-trigger-example--scripting-) и [RunLevel](https://learn.microsoft.com/en-us/windows/win32/taskschd/principal-runlevel). Задача создаётся только при включении переключателя, а не при сборке или открытии окна. Регистрация не запускает приложение немедленно.

Переключатель показывает фактическое состояние задачи. Если она указывает на старую сборку, появится «Привязать эту версию». После переноса папки или смены exe обновите привязку из новой версии. Файлы engine и профилей должны оставаться рядом с exe. Выключение переключателя удаляет задачу и не останавливает текущее подключение. При ошибке запуска движка приложение покажет окно с журналом; второй экземпляр при автозапуске завершается без диалога.

Задача не создавалась и запуск при входе не проверялся: выполнены только сборка и автономные проверки XML/параметров без обращения к Планировщику.

Каждый новый лучший профиль, подтвердивший улучшение двумя проверками, сразу выбирается в списке и сохраняется как выбор по умолчанию. Он восстанавливается после перезапуска приложения. Отмена последующего перебора сохраняет уже найденный выбор. Автоматического включения движка после подбора нет.

В `Zapretus-selection-fix.exe` итог подбора отдельно отображается в карточке стратегии и строкой «ИТОГ ПОДБОРА» в журнале. При равенстве баллов остаётся первый подтверждённый вариант; строка проверки последнего кандидата не означает его победу. Ручной выбор в списке сохраняется независимо от результата предыдущего подбора.

1. Откройте папку `dist`. Сохраняйте её содержимое вместе: `Zapretus-lab.exe`, `profiles.xml`, `experimental-profiles.xml`, `engine`.
2. Закройте предыдущую версию через «Выключить и выйти» в трее. Запустите `Zapretus-lab.exe` двойным щелчком. Windows запросит права администратора.
3. Если уже работает другой zapret (в том числе как служба), остановите его через его штатное меню. Приложение не останавливает чужие процессы.
4. Выберите «Основная», нажмите «Включить». Статус «Движок работает» означает запуск процесса, а не подтверждение обхода.
5. Откройте YouTube и воспроизведите видео, затем проверьте подключение к голосовому каналу Discord.
6. Если не работает, выключите движок и нажмите «Подобрать стратегию». Подбор сначала проверяет LAB, затем исходные профили. Профиль сохраняется только при подтверждённом улучшении относительно двух проверок без обхода. Движок после подбора выключен. Затем нажмите «Включить» и повторите ручную проверку.

## Что изменено в LAB

### Game Filter

В сборке `Zapretus-gamefilter.exe` есть переключатель Game Filter и ссылка «Настроить порты». По умолчанию выключен; начальный режим UDP, диапазон `1024-65535`. Доступны TCP, UDP, TCP + UDP и списки портов, например `27015,27020-27030`. Настройки сохраняются в `%LOCALAPPDATA%\Zapretus\game-filter.xml`.

Сначала выключите движок, переключите Game Filter, при необходимости настройте порты, затем снова включите движок. Управление заблокировано во время работы движка и подбора; подбор использует текущие настройки Game Filter.

Фильтр работает для адресов из `engine/lists/ipset-all.txt`, с учётом IP-исключений. Этот список поставляется с тестовым адресом; добавьте IP/CIDR нужной игровой службы, если их там нет. Включение переключателя само по себе не добавляет адреса игр. Исходные профили сохраняют свои игровые методы, LAB получает отдельные игровые правила. Проверка голоса и игр остаётся ручной.

Матрица профилей задаётся в `scripts/experimental_profiles.py` независимо от batch-файлов Flowseal:

| Параметр | Варианты |
|---|---|
| TCP-обработка | `multisplit`, `multidisorder` |
| Точка разделения | `1`, `midsld` |
| Повторы UDP fake | `2`, `6` |

Получаются 8 комбинаций. TCP/QUIC ограничены доменами YouTube/Discord и исключениями; голосовые UDP-порты фильтруются по распознаванию Discord/STUN. Это экспериментальные комбинации [документированных методов zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.en.md), а не новый алгоритм перехвата пакетов или доказанно лучшие настройки. Исполняемые файлы движка не изменялись.

Диагностика проверяет страницу и изображение YouTube, содержимое ответа Discord API, изображение Discord CDN и получение Hello по WebSocket Discord. Авторизация и токен Discord не нужны. Баллы: страница/изображение/CDN — по 1, API — 2, WebSocket — 3, медиаданные — 5. Ни один выигрыш не принимается ценой потери ранее проходившего теста. Кандидат повторно проверяется после перезапуска движка и должен сохранить все успехи первой проверки.

Каждая проверка выполняет новые соединения, обходя системный HTTP-прокси. Если используете VPN, результат относится к текущему маршруту через него. При смене сети нужен новый подбор; сохранённый профиль общий, автоматической привязки к провайдеру пока нет.

### Как включить проверку медиаданных

1. Откройте видео YouTube в браузере, нажмите F12 и откройте вкладку Network / Сеть.
2. Найдите запрос `videoplayback` к узлу `…googlevideo.com`. Скопируйте его URL через Copy URL / Копировать адрес ссылки (не Copy as cURL).
3. В Zapretus нажмите «Ссылка для медиатеста» и вставьте URL. Обычная ссылка `youtube.com/watch` не подходит.
4. Запустите «Диагностика» или подбор. За проверку скачивается не более 256 КиБ; успех требует минимум 64 КиБ и тип содержимого video/audio. Это проверка передачи данных, а не полноценное воспроизведение или замер скорости.

Ссылка подписана и действует временно. Она хранится только в памяти до закрытия приложения, не записывается в журнал/CSV. Ответ 403 может означать истечение срока ссылки; скопируйте свежую. Если браузер не может получить ссылку, тест можно оставить выключенным. Без ссылки медиатест помечается «ПРОПУСК», а не успехом или сбоем.

QUIC и голосовой UDP-трафик автоматически не проверяются. Успешный WebSocket подтверждает только доступ к Discord Gateway, а не голосовому каналу. Если все измеряемые проверки уже проходят без обхода, подбор не меняет профиль: добавьте медиатест или проверяйте видео/голос вручную. Полный перебор может занять 10–15 минут; есть отмена.

После диагностики/подбора в `%LOCALAPPDATA%\Zapretus` появляется `scan-*.csv`: результаты по тестам, пропуски, объём данных, длительность, ошибки запуска. Это материал для следующей настройки, включая случаи, когда улучшения нет. Отмена сохраняет уже записанные строки и последний подтверждённый выбор профиля.

«Свернуть в трей» сохраняет движок работающим. Закрытие окна или «Выключить и выйти» в трее завершает собственный движок. После аварийного завершения интерфейса Windows также завершает привязанный процесс через Job Object. Системная служба не устанавливается; автозапуск через Планировщик включается только переключателем. Приложение не меняет DNS или настройки антивируса.

Профиль и журналы: `%LOCALAPPDATA%\Zapretus`. Дополнительные домены: `dist/engine/lists/list-general-user.txt`, исключения: `list-exclude-user.txt` (один домен на строку). После изменений перезапустите движок кнопками.

## Сборка

На Windows x64 с .NET Framework 4.8 и Python 3:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -OutputName Zapretus-lab.exe
```

SDK .NET и пакеты NuGet не нужны. Сборка не запускает приложение или движок.
`prepare_engine.py` извлекает только аргументы winws, не исполняя bat-файлы, проверяет наличие всех используемых ресурсов. Исходный архив и SHA-256 файлов указаны в `dist/upstream-manifest.json`. Это фиксация скачанных файлов, а не независимая криптографическая проверка издателя.
