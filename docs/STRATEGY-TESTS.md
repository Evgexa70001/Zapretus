# Проверка новых стратегий — 18 ноября 2026

Восемь старых LAB удалены из генератора и поставляемого XML. Вместо них добавлены три варианта на основе исходного `general (ALT)`: сохранены списки доменов Google и общих сервисов, исключения, правила Discord UDP и Game Filter. Варианты отличаются методом разделения TCP и числом повторов поддельных пакетов.

Тест выполнен на текущем подключении с выключенным Game Filter. Каждый вариант запускался заново для каждого из двух проходов; после проверки тестовый движок остановлен.

| Вариант | Проход 1 | Проход 2 |
| --- | --- | --- |
| Без обхода | 0/5 | 0/5 |
| CUSTOM 1 - FakeSplit TS | 5/5 | 5/5 |
| CUSTOM 2 - MultiSplit TS | 5/5 | 5/5 |
| CUSTOM 3 - MultiDisorder TS | 5/5 | 5/5 |

Проверены страница YouTube, изображение с ytimg, Discord API, изображение с Discord CDN и получение Discord Hello по WebSocket. Во всех успешных ответах проверено содержимое, а не только HTTP-статус. Балл каждого нового варианта: 8 из 8, против 0 без обхода.

Загрузка самих видеоданных не проверялась: прямая ссылка googlevideo не задана. Голосовой канал Discord, QUIC и игровые соединения этими тестами не подтверждены. Результат относится к текущему подключению и времени проверки.

Подробные результаты: `dist/network-tests.log` и `dist/scan-20261118-180218-212.csv`. Использованные параметры находятся в `dist/experimental-profiles.xml`.

Для повторения: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-network.ps1`. Требуются права администратора; перед тестом выключите подключение в приложении и остановите другие экземпляры zapret. Тест не изменяет выбранную стратегию или автозапуск.

Автономные проверки: тест генератора профилей и 406 проверок C# прошли успешно.
